# Detecting Battery Failure Before Thermal Runaway

A public research-portfolio website for my UCL MSc project on anomalous voltage responses preceding thermal runaway in cylindrical lithium-ion batteries.

**Live website:** https://jefferylegolas.github.io/lithium-battery-thesis/

**Full MSc thesis (PDF):** https://jefferylegolas.github.io/lithium-battery-thesis/thesis.pdf

## Research focus

The study investigates two discrete voltage-drop events observed before rapid thermal escalation in a fully charged B18650CX-20M cylindrical lithium-ion cell. The second voltage collapse is followed by substantial recovery, motivating a mechanism-focused comparison between transient electrical connection changes, pressure/top-cap protection behaviour and localized internal shorting.

## Methods

- Accelerating Rate Calorimetry (ARC)
- X-ray computed tomography (CT)
- Differential Scanning Calorimetry (DSC)
- Thermogravimetric Analysis (TGA)
- X-ray Diffraction (XRD)

## Key result

Two discrete pre-runaway voltage anomalies were observed, including a large collapse followed by recovery. The result suggests terminal voltage may provide a useful complementary early-warning signal alongside temperature and self-heating rate.
